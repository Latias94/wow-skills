# 指标与因果判定口径

## 总览指标

| 指标 | 计算/来源 | 解读注意 |
| --- | --- | --- |
| 遭遇 DPS | 总伤害 ÷ 战斗时长 | 用于同一战斗横向比较；要标注是否包含宠物/复制体 |
| 存活 DPS | 总伤害 ÷ 有效存活时间 | 死亡玩家可能被这个数字“美化”，不能替代遭遇 DPS |
| 有效存活率 | 存活时间 ÷ 战斗时长 | 死亡、掉线和长时间无目标先解释这个指标 |
| 施法密度 | 实际 `cast` 次数 ÷ 分钟 | 不把 `begincast` 当成完成施法；瞬发、移动和通道要结合场景 |
| 技能覆盖 | 增益/减益区间 ÷ 可用战斗时间 | 自动刷新、叠层和离场期间不能简单按整场百分比判错 |
| 资源浪费 | WCL `resourcechange`、溢出或上限事件 | 没有溢出不等于管理优秀，也可能只是资源生成低 |
| 窗口伤害 | 指定阶段/机制窗口内伤害 | 先对齐阶段边界和目标存活，再比较数值 |

## 技能执行

对每个关键技能同时记录：次数、每分钟次数、相对时间、目标、命中/免疫、当时的增益、前后一个公共冷却和阶段。

判断“漏按”需要满足：

1. 当前构筑确实让技能在该时间可用（先核对减冷却、充能、重置和自动施放）。
2. 该阶段存在有效目标，且不是移动、免疫、转火或团队职责导致的合理延后。
3. 相邻事件显示玩家有可用公共冷却，而不是读条被打断或正在处理更高优先级动作。
4. 至少有一个可比样本在相同窗口使用，或理论冷却轴明确支持这个判断。

否则用“可能少用/延后/目标选择不同”，不要写成确定失误。

## 爆发对齐

对每次主要冷却建立窗口，检查：

- 开始时间与阶段/小怪波次的关系。
- 药水、饰品、套装触发、英雄天赋和外部增益是否重叠。
- 关键技能是在增伤开始前预铺，还是在增伤结束后才落地。
- 是否因为过早使用导致高价值阶段少一次爆发。
- 结束后是否有自动复制、免费终结技、资源返还或 DoT 延续。

“冷却好了就按”不一定正确；“一定要等到某秒”也不一定正确。先计算这一场的阶段收益和下一次可用时间，再评价延后成本。

## 目标与顺劈

目标分析至少拆成：主目标、优先小怪、其他小怪、无效/免疫。比较：

- 关键技能是否打在应打目标上。
- AOE 技能是否在目标活得足够久时使用。
- 直伤、DoT、复制体和宠物是否受益于正确的目标/位置。
- 转火前是否过度铺垫快死目标。
- 地面技能是否落在目标实际站位，是否有免疫或脱离。

对小怪首领，目标分配的“每次施法价值”可能比总施法次数更重要；必须同时看次数和每次命中的伤害。

## 增益、复制体与自动效果

很多专精的高分差距来自“一个施法触发了多少后续效果”，而不是按钮数量。核对：

- 增益是玩家主动施放、天赋触发还是爆发自动施加。
- 复制体/宠物的伤害归属和持续时间。
- 套装是否把某个技能转成免费施法或延后结算。
- 天赋是否改变冷却、目标上限、暴击、资源或 DoT 覆盖。
- 触发事件是否发生在目标仍存活的窗口。

日志中出现“同一技能伤害很高”时，先找触发链和目标分布，再判断是否值得模仿。

## 死亡与团队级联

记录死亡相对时间、致死技能、死亡前 3-5 秒的伤害序列、可用防御和团队已经死亡人数。进度战中，前两次死亡是个体诊断重点；其后的级联死亡不应直接归罪于个人。

## 因果置信度

- **高**：事件直接证明，替代解释已排除，例如死亡后没有施法、技能在免疫目标上命中为零。
- **中**：日志与当前机制一致，但缺少职责/站位或完整增益数据。
- **低**：只看到总伤害或单个样本，可能由装备、团队、运气或阶段差异造成。

每条建议都要写成：

```text
事实 → 机制后果 → 最可能原因 → 下一把动作 → 验证指标 → 置信度
```
