# WCL 复盘报告模板

根据输入完整度裁剪，不要为了填模板而制造结论。

## 第一屏：结论

```text
一句话结论：差距最大的 1-3 个来源是什么。
可比性：高 / 中 / 低；主要偏差是什么。
下一把只练：动作 A、动作 B（各带一个验证指标）。
```

## 战斗背景

```text
报告 / 战斗：<代码> / <fight>
首领与难度：<名称>
时长：<战斗时长>；玩家有效存活：<时间/百分比>
玩家：<角色>；源 ID：<id>
构筑：<专精 / 英雄天赋 / 套装>
基准：<同场玩家或 3-5 个样本；装等与任务差异>
```

## 时间线

按相对战斗时间写：

```text
0:00-0:20 开场：预铺、药水、第一轮爆发、触发链
<阶段/波次>：玩家与基准的关键技能顺序和目标
<第二轮爆发>：是否对齐高价值窗口
<结束阶段>：死亡、斩杀、资源或最后一次爆发
```

只列会改变结论的事件；完整原始时间线放在本地摘要或附录，不要让用户在噪声里找重点。

## 问题卡

每个主要问题使用：

```text
### 问题 1：<简短标题>
日志事实：<时间、次数、伤害、目标或覆盖率>
机制后果：<少了什么触发/增伤/目标价值>
最可能原因：<执行 / 任务 / 机制 / 装备>
下一把动作：<一个可观察动作>
验证指标：<WCL 中的具体数字或时间点>
置信度：高 / 中 / 低
```

## 装备与天赋

单独列出：

- 事实差异：装等、主属性、绿字、饰品、套装和天赋节点。
- 预期影响：方向性说明，不伪造精确 DPS。
- 是否需要 `/simc`：只有在执行差距已经相近时才把它列为主要下一步。
- 辅助天赋与伤害天赋：不要把打断、驱散、位移、生存节点误判为伤害损失。

## 经验小结

输出 1-3 张可复制经验卡，格式见 `experience-capture.md`。每张卡都要带适用场景和验证指标。
